Merge confirmation codes

Adds confirmation codes to your existing encrypted set and writes a new secrets.enc.js. Everything happens in this page — the passphrase and the codes never leave your computer, and nothing is sent anywhere. This copy ships with the repo and holds no codes of its own, so it is safe to publish; type them in below.

1 — Your current secrets file

Needed so the Italy and Singapore codes survive the merge. Without it you'd overwrite them.

2 — Family passphrase

Used to decrypt what's there and re-encrypt the merged set.

3 — Codes to add

These keys match the codeKey fields already in trip-data.js, so they'll appear on the right cards once merged.

Afterwards: replace secrets.enc.js in the Andiamo folder with the downloaded file, then commit and push. Only ciphertext gets published. If you save a copy of this page with the codes typed in, name it secrets-merge.html — that name is git-ignored, so it can't be committed by accident.
